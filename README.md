# PorciData: datos públicos

Corte inicial verificado: boletín #21 de Porkcolombia–FNP, 9 de octubre de 2026. Unidad COP/kg. Datos de la Quincena Actual; ausencias conservadas como null. Referencias informativas, no precios obligatorios.

Fuente oficial: https://porkcolombia.co/wp-content/uploads/2026/10/Quincena21de2026.pdf

`datos.json` conserva precios nacionales y regionales, cobertura, referencia anterior, variaciones calculadas y huella del PDF. Las variaciones nacionales no implican una muestra regional constante. Central Ganadera y SIPSA no se mezclan con estos indicadores.

Esta carga inicial no activa actualización automática. El lector y sus pruebas permanecen en otro repositorio privado. No se incluyen credenciales ni datos personales.
